# Сайт-приглашение 25.05.2027 — версия 2

В этой версии три страницы основаны непосредственно на предоставленном широком изображении макета. Поэтому композиция, расположение даты, фотографии, колец, теплохода и декоративных фигур сохраняются намного точнее, чем при ручной сборке каждого элемента в CSS.

Анкета размещена поверх свободной области третьего постера.

## Проверка
Откройте `index.html` в браузере. На компьютере страницы показаны рядом; на узком экране они идут вертикально.

## Важно
Форма пока демонстрационная: ответы сохраняются только в локальном хранилище текущего браузера и не отправляются организаторам. Перед рассылкой гостям необходимо подключить сервис приёма ответов (например, Tally или Google Forms) и проверить тестовую отправку.

## Файлы
- `index.html` — страницы и форма
- `style.css` — расположение страниц и анкеты
- `script.js` — демонстрационная обработка формы
- `assets/poster-1.jpg`, `poster-2.jpg`, `poster-3.jpg` — три панели макета


### Анкета гостей
Анкета встроена через Google Forms и отправляет ответы напрямую в форму «Кейт и Илья — 25.05.2027». Если встроенная форма не отображается в браузере, внутри блока есть ссылка для открытия анкеты отдельно. Ответы нужно смотреть во вкладке «Ответы» Google Forms; при желании там же можно связать форму с Google Sheets.
